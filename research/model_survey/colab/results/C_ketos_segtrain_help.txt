Usage: ketos segtrain [OPTIONS] [GROUND_TRUTH]...

  Trains a baseline labeling model for layout analysis

Options:
  -o, --output PATH               Output model file  [default: model]
  -s, --spec TEXT                 VGSL spec of the baseline labeling network
                                  [default: [1,1800,0,3 Cr7,7,64,2,2 Gn32
                                  Cr3,3,128,2,2 Gn32 Cr3,3,128 Gn32 Cr3,3,256
                                  Gn32 Cr3,3,256 Gn32 Lbx32 Lby32 Cr1,1,32
                                  Gn32 Lby32 Lbx32]]
  --line-width INTEGER            The height of each baseline in the target
                                  after scaling  [default: 8]
  --pad <INTEGER INTEGER>...      Padding (left/right, top/bottom) around the
                                  page image  [default: 0, 0]
  -i, --load PATH                 Load existing file to continue training
  -F, --freq FLOAT                Model saving and report generation frequency
                                  in epochs during training. If frequency is
                                  >1 it must be an integer, i.e. running
                                  validation every n-th epoch.  [default: 1.0]
  -q, --quit [early|dumb]         Stop condition for training. Set to `early`
                                  for early stopping or `dumb` for fixed
                                  number of epochs  [default: dumb]
  -N, --epochs INTEGER            Number of epochs to train for  [default: 50]
  --min-epochs INTEGER            Minimal number of epochs to train for when
                                  using early stopping.  [default: 0]
  --lag INTEGER                   Number of evaluations (--report frequence)
                                  to wait before stopping training without
                                  improvement  [default: 10]
  --min-delta FLOAT               Minimum improvement between epochs to reset
                                  early stopping. By default it scales the
                                  delta by the best loss
  -d, --device TEXT               Select device to use (cpu, cuda:0, cuda:1,
                                  ...)  [default: cpu]
  --precision [64|32|bf16|16]     Numerical precision to use for training.
                                  Default is 32-bit single-point precision.
                                  [default: 32]
  --optimizer [Adam|SGD|RMSprop|Lamb]
                                  Select optimizer  [default: Adam]
  -r, --lrate FLOAT               Learning rate  [default: 0.0002]
  -m, --momentum FLOAT            Momentum  [default: 0.9]
  -w, --weight-decay FLOAT        Weight decay  [default: 1e-05]
  --warmup FLOAT                  Number of steps to ramp up to `lrate`
                                  initial learning rate.  [default: 0]
  --schedule [constant|1cycle|exponential|cosine|step|reduceonplateau]
                                  Set learning rate scheduler. For 1cycle,
                                  cycle length is determined by the `--step-
                                  size` option.  [default: constant]
  -g, --gamma FLOAT               Decay factor for exponential, step, and
                                  reduceonplateau learning rate schedules
                                  [default: 0.1]
  -ss, --step-size INTEGER        Number of validation runs between learning
                                  rate decay for exponential and step LR
                                  schedules  [default: 10]
  --sched-patience INTEGER        Minimal number of validation runs between LR
                                  reduction for reduceonplateau LR schedule.
                                  [default: 5]
  --cos-max INTEGER               Epoch of minimal learning rate for cosine LR
                                  scheduler.  [default: 50]
  -p, --partition FLOAT           Ground truth data partition ratio between
                                  train/validation set  [default: 0.9]
  -t, --training-files FILENAME   File(s) with additional paths to training
                                  data
  -e, --evaluation-files FILENAME
                                  File(s) with paths to evaluation data.
                                  Overrides the `-p` parameter
  --workers INTEGER               Number of OpenMP threads and workers when
                                  running on CPU.  [default: 1]
  --load-hyper-parameters / --no-load-hyper-parameters
                                  When loading an existing model, retrieve
                                  hyper-parameters from the model  [default:
                                  no-load-hyper-parameters]
  --force-binarization / --no-binarization
                                  Forces input images to be binary, otherwise
                                  the appropriate color format will be auto-
                                  determined through the network
                                  specification. Will be ignored in `path`
                                  mode.  [default: no-binarization]
  -f, --format-type [path|xml|alto|page]
                                  Sets the training data format. In ALTO and
                                  PageXML mode all data is extracted from xml
                                  files containing both baselines and a link
                                  to source images. In `path` mode arguments
                                  are image files sharing a prefix up to the
                                  last extension with JSON `.path` files
                                  containing the baseline information.
  --suppress-regions / --no-suppress-regions
                                  Disables region segmentation training.
                                  [default: no-suppress-regions]
  --suppress-baselines / --no-suppress-baselines
                                  Disables baseline segmentation training.
                                  [default: no-suppress-baselines]
  -vr, --valid-regions TEXT       Valid region types in training data. May be
                                  used multiple times.
  -vb, --valid-baselines TEXT     Valid baseline types in training data. May
                                  be used multiple times.
  -mr, --merge-regions TEXT       Region merge mapping. One or more mappings
                                  of the form `$target:$src` where $src is
                                  merged into $target.
  -mb, --merge-baselines TEXT     Baseline type merge mapping. Same syntax as
                                  `--merge-regions`
  -br, --bounding-regions TEXT    Regions treated as boundaries for
                                  polygonization purposes. May be used
                                  multiple times.
  --augment / --no-augment        Enable image augmentation  [default: no-
                                  augment]
  --resize [add|union|both|new|fail]
                                  Output layer resizing option. If set to
                                  `add` new classes will be added, `both` will
                                  set the layer to match exactly the training
                                  data classes, `fail` will abort if training
                                  data and model classes do not match.
                                  [default: fail]
  -tl, --topline                  Switch for the baseline location in the
                                  scripts. Set to topline if the data is
                                  annotated with a hanging baseline, as is
                                  common with Hebrew, Bengali, Devanagari,
                                  etc. Set to  centerline for scripts
                                  annotated with a central line.
  -cl, --centerline
  -bl, --baseline
  --logger [tensorboard]          Logger used by PyTorch Lightning to track
                                  metrics such as loss and accuracy.
  --log-dir PATH                  Path to directory where the logger will
                                  store the logs. If not set, a directory will
                                  be created in the current working directory.
  --help                          Show this message and exit.
