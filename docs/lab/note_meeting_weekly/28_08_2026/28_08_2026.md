## 5. Điều chỉnh chiều 28/08 (trao đổi)

Qwen **phải có output thật**. Hương **chạy hết** OCR→âm→nghĩa rồi so với bản Hương. Tài liệu Quốc ngữ **không** đi pipeline Hán.

### Qwen — cần gì (không phải pull 37B)

Repo **chưa có** client Qwen. `.env` có `HANNOM_*` + `GOOGLE_API_KEY` (Gemini) — **không** có token Qwen. Thầy: xin API-key; T đã thử **Qwen 3.6 27B** dịch nghĩa; FT **37B** là track khác (máy lab, tuần sau).

| Cần | Có sẵn? | Ghi chú |
|-----|---------|---------|
| Token / endpoint Qwen (DashScope hoặc URL lab) | **Thiếu** | Nhắn T; không thay bằng Gemini khi báo cáo «Qwen» |
| Tên model | **Thiếu** | Xác nhận 27B (API thử) vs 37B (FT) |
| Wrapper gọi API | **Thiếu** | ~1 file tool; OpenAI-compatible nếu DashScope |
| `git pull` weights 37B | **Không** tuần này | Chỉ khi FT local |
| GPU / máy lab | **Không** cho 1 trang API | |
| Data 1 trang Hán | **Có** | Paddle Hương p.9 (sạch) hoặc tế văn RTL đã hiệu đính |
| Gold so | **Có, lỏng** | Ô.cố §2/§5 (paraphrase); tế văn `text.txt` sát hơn |

Khi có key: 1 trang kế ước p.9 → `dich/9-qwen.md` → bảng so Ô.cố. Chưa FT.

**Không xin thầy:** tự tạo `DASHSCOPE_API_KEY` (cùng `qwen3.6-27b` T đã thử). Tool: `nlp_family_extractor/tools/dich_qwen.py`. Máy Intel 32GB **không** load 27B local. Series 3.6 **không có** 37B (T nói 37B ≈ nhầm 27B dense / 35B-A3B MoE).

### Hương Hán-Nôm — không OCR lại 15 trang

Paddle **đã xong** 15/15 (`PP-OCRv6_medium`, mean ~0.70). Việc còn:

```
Paddle OCR (xong)
  → phiên âm lab trên *chữ Paddle*  (`dich_hannom_catalog.py --book nguyen-ke-han-nom`)
  → dịch nghĩa Qwen (khi có key; tạm 1–3 trang sạch: 9, 10, 14, 2)
  → so Ô.cố + ghi chú Hương trong Word
```

Lab **OCR ảnh** 0/15 (`access_denied` lần trước) — **không chặn** phiên âm: API lab nhận **text**, không cần bbox. Retry phiên âm với `HANNOM_EMAIL` đã có trong `.env`.

So sánh với Hương = Ô.cố (dịch lỏng) + bằng khoán Diên Khánh.docx. **Không** lấy `Nguyễn Kế gia phả/` (ảnh Quốc ngữ) làm gold Hán. Mục §5 Ô.cố lệch tên (Thị vs 阮) — giữ cả hai, đánh dấu lỗi dịch.

`Nguyễn Kế gia phả/` (53 ảnh QN): **không** Paddle Hán. Nếu cần chữ tuần này: Paddle **Latin** 3–5 trang, hoặc để nguyên ảnh.
